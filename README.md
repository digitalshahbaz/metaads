# metaads

All DigiMark Media / Digital Shahbaz marketing work in one place.

## Folder structure

| Folder | What goes in it |
|---|---|
| [`campaigns/`](campaigns) | Meta ad campaign plans, structures, budgets, launch notes |
| [`ad-copy/`](ad-copy) | Hooks, headlines, primary text, ad angles, video scripts |
| [`creatives/`](creatives) | Ad images, videos, and image-generation prompts ([`creatives/prompts/`](creatives/prompts)) |
| [`landing-pages/`](landing-pages) | Landing, opt-in, sales and booking page copy and HTML |
| [`funnels/`](funnels) | Funnel maps, email / WhatsApp sequences, webinar & workshop funnels |
| [`offers/`](offers) | Offer creation, pricing, value stacks, positioning |
| [`tracking/`](tracking) | Meta Pixel, CAPI, GoHighLevel setup and diagnostics |
| [`reports/`](reports) | Weekly / monthly performance reports and audits |
| [`clients/`](clients) | Client briefs and onboarding notes (one subfolder per client) |
| [`templates/`](templates) | Reusable SOPs, checklists, templates |
| [`assets/`](assets) | Logos, brand kits, photos, reference files |

## Tip

Inside `campaigns/`, `clients/` and `reports/`, make one subfolder per client, e.g. `clients/acme-coaching/`.
